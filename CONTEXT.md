# algeria-delivery-offices — Algeria Delivery Offices Directory

> ID: ECO-06  
> Category: `ecommerce`

> Stack: Vanilla JavaScript, HTML5, CSS3, JSON datasets

## One Job
Visual interactive directory and address lookup tool for Algerian courier stop-desk and delivery offices across all 58 wilayas.

## Context & Inputs
- **Codebase Root**: `./`
- **Frontend**: `index.html`, `data.js`, `offices.json`
- **Images**: `صور/`
- **Shared Reference**: `../../../_shared/rules.md`

## Commands
```bash
# Open directly in browser or serve with local HTTP server
npx serve .
# or python -m http.server 8000
```

## Outputs
- Lightweight interactive client-side web directory for desk stops and pickup stations.

## Human Gate & Verification
Verify office phone numbers, wilaya filtering, and address coordinates in `offices.json`.
